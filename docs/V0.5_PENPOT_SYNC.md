# v0.5 Penpot bidirectional sync

DesignBridge v0.5 proves the first safe round-trip workflow between canonical DesignBridge JSON and already-linked Penpot objects.

## Penpot -> DesignBridge

The Penpot plugin serializes selected linked shapes with:

- Penpot shape ID
- DesignBridge ID/type
- name/type
- x/y
- width/height
- text content for text shapes
- first fill color when available

The plugin can copy this snapshot as JSON.

DesignBridge accepts the snapshot at:

`POST /api/penpot/compare`

The backend compares each linked Penpot shape with the canonical node and produces normal DesignBridge `update_node` operations. Those operations go through the same deterministic validation/dry-run path as AI-generated changes.

The browser UI exposes a **Penpot selection snapshot** box, **Compare Penpot**, and **Accept Penpot changes**.

## DesignBridge -> existing Penpot

The plugin can also take the current DesignBridge JSON and update linked shapes on the current Penpot page in place.

Currently updated in place:

- name
- x/y
- width/height
- direct fill
- text characters

This uses the stored `designbridge:id` plugin data rather than relying on Penpot shape IDs, so DesignBridge identity remains stable even when Penpot's own object identity is installation/file specific.

## Safety boundary

v0.5 deliberately does not reverse-sync these yet:

- token-bound fills into direct fill overrides
- layout structure/reparenting
- component definition changes
- add/remove operations inferred from missing shapes
- typography
- constraints
- variants
- interactions/prototyping

Those require richer semantic mapping and should not be guessed from visual geometry alone.

## Current round-trip

```text
DesignBridge JSON
      |
      v
Penpot linked shapes
      |
   user edits
      |
      v
selection snapshot
      |
      v
compare -> DesignBridge operations
      |
      v
preview / accept
      |
      v
canonical JSON
      |
      v
update linked shapes in place
```

## Next milestone

The next useful slice is direct local transport between DesignBridge and the Penpot plugin, removing the copy/paste snapshot step. After that, extend synchronization to layout semantics and design-token bindings.
