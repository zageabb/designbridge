# v0.4 Revisions and Penpot round-trip groundwork

DesignBridge v0.4 adds durable project history and the first Penpot read-back hook.

## Project revisions

Designs can now be saved into a local SQLite project store. Every save creates an immutable revision.

Supported actions:

- list projects;
- save a revision;
- load current or historical revisions;
- view revision history;
- undo to the previous revision;
- redo to the next revision;
- branch safely after undo (future redo revisions are discarded when a new save is made).

The browser UI exposes **Save revision**, **Undo**, and **Redo**.

## Selection-aware AI

The AI proposal endpoint accepts an optional `selection_ids` array. These DesignBridge IDs are included in the model context so instructions can be scoped to the selected design objects rather than the whole document.

## Penpot read-back hook

The Penpot plugin now uses the current plugin API's `penpot.selection` property and `selectionchange` event to report selected shapes. Each selection record includes:

- Penpot shape ID;
- stored DesignBridge ID;
- stored DesignBridge type;
- name/type;
- position and dimensions.

This does not yet mutate DesignBridge from Penpot. It establishes the identity bridge required for a safe future compare/update workflow.

## Next slice

The next milestone should add:

1. node snapshots from Penpot;
2. compare Penpot snapshot against the canonical DesignBridge node;
3. reviewable reverse operations;
4. update-in-place push from DesignBridge to existing Penpot shapes instead of creating a fresh import.
