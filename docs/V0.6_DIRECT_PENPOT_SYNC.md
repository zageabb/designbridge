# v0.6 Direct Penpot sync

DesignBridge v0.6 removes the manual copy/paste step from the normal Penpot workflow.

## Direct transport

The Penpot plugin talks directly to the local DesignBridge API over HTTP.

Default local API:

```text
http://127.0.0.1:5087
```

The plugin can remember a custom API URL and exposes:

- **Test connection**
- **Pull latest**
- **Push selection**

The linked DesignBridge project ID is read from Penpot file plugin data that was written during import.

## Pull latest

`GET /api/penpot/projects/{project_id}/current`

The plugin fetches the latest saved DesignBridge revision, loads it into the plugin JSON view, and updates existing linked Penpot shapes in place.

## Push selection

`POST /api/penpot/projects/{project_id}/selection`

The plugin sends the current selected linked Penpot shapes directly to DesignBridge.

DesignBridge:

1. loads the current canonical project;
2. compares the Penpot snapshot with linked DesignBridge nodes;
3. creates normal deterministic reverse operations;
4. validates the resulting document;
5. saves it as a new project revision;
6. returns the updated canonical document.

## CORS and local network access

DesignBridge explicitly allows the local plugin server and Penpot web origins to call the API.

Some Chromium-based browsers can block HTTPS pages from talking to localhost until local-network access is allowed. Penpot documents the same limitation for its local MCP workflow. Firefox can also be used for local testing when browser policy gets in the way.

## Fallback

JSON paste/load, snapshot copy, and manual update controls remain available as a fallback and debugging path.
