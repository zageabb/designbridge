# v0.7 Semantic layout sync

DesignBridge v0.7 extends the Penpot round-trip to supported flex-layout semantics.

## Supported layout properties

The following DesignBridge layout properties now synchronize in both directions:

- direction: horizontal / vertical
- gap
- padding
- alignment: start / center / end / stretch

## Penpot -> DesignBridge

Penpot board selection snapshots now include supported flex layout values when available.

The backend compares those values to the canonical DesignBridge `Layout` object and produces a normal `update_node` operation containing a validated replacement layout.

Missing layout snapshot fields are ignored. DesignBridge does not infer layout changes from geometry alone.

## DesignBridge -> Penpot

When updating an existing linked Penpot board, DesignBridge now applies supported flex settings to the board's existing layout object rather than recreating the board.

## Safety boundary

v0.7 still does not reverse-sync:

- structural reparenting
- child ordering inferred from canvas position
- grid layout
- component main-definition changes
- instance override semantics
- responsive constraints
- typography tokens
- interaction/prototype settings

These will be added only when there is a clear semantic mapping.

## Next milestone

The next useful step is connection state and automatic revision awareness:

1. expose latest project revision metadata;
2. let the Penpot plugin poll or refresh for newer DesignBridge revisions;
3. show local-vs-remote revision state;
4. make pull/push conflict-aware instead of last-write-wins.
