# v0.9 Passive revision awareness

DesignBridge v0.9 adds non-destructive revision awareness to the Penpot plugin.

## Passive status polling

The plugin polls the DesignBridge project status every 30 seconds while a linked project is open.

It never modifies the Penpot canvas automatically.

## Update indicator

When DesignBridge has moved beyond the Penpot file's last synchronized revision, the plugin shows an **update available** badge and the latest revision description.

## Review latest

The new **Review latest** action fetches the latest canonical DesignBridge revision and places its JSON into the plugin editor for inspection.

This does not update any Penpot shapes and does not change the stored Penpot revision.

## Pull latest

The existing **Pull latest** action remains the explicit operation that:

1. fetches the latest canonical revision;
2. updates linked Penpot shapes in place;
3. updates the Penpot file's stored revision;
4. returns the sync state to `in_sync`.

## Conflict safety

Push remains blocked when Penpot is behind DesignBridge.

The passive polling introduced here does not bypass or weaken the v0.8 revision precondition.

## Next milestone

The next useful slice is reviewable change summaries between revisions:

- compare the Penpot-linked revision to the latest DesignBridge revision;
- show changed node IDs and properties;
- let the user decide whether to pull all changes or selected supported changes.
