# v0.13 Property-level conflict resolution

DesignBridge v0.13 lets Penpot users resolve each outstanding property explicitly after a three-way review.

## Choices

For every conflicting, local-only, or remote-only property the user must choose:

- **Keep Penpot** — preserve the current local Penpot value and write it into the canonical DesignBridge document.
- **Use DesignBridge** — apply the current canonical DesignBridge value to the Penpot property.

## Atomic completion

Resolution is treated as a complete reconciliation step.

The plugin will not mark the Penpot file synchronized until every outstanding property has an explicit choice.

Partial resolution plans are reviewable but do not advance the stored Penpot revision.

## Canonical behavior

When one or more **Keep Penpot** choices are selected:

1. DesignBridge applies those local values as deterministic `update_node` operations to the latest canonical document;
2. the resulting document is validated;
3. a new DesignBridge revision is saved;
4. Penpot records that final new revision after the remote property updates are applied.

When every choice is **Use DesignBridge**, no redundant canonical revision is created. Penpot simply applies the selected latest values and advances to the existing latest revision.

## Supported properties

The same safe semantic properties supported by three-way review can be resolved:

- name
- x / y
- width / height
- text
- direct fill when not token-bound
- supported flex layout

## API

`POST /api/penpot/projects/{project_id}/resolve-properties`

Example:

```json
{
  "from_revision": 4,
  "snapshots": [],
  "resolutions": [
    {
      "node_id": "title",
      "property": "text",
      "choice": "local"
    },
    {
      "node_id": "kpi-row",
      "property": "layout",
      "choice": "remote"
    }
  ]
}
```

The response includes:

- resolved and unresolved properties;
- narrow Penpot property updates;
- canonical local changes;
- final canonical document;
- final synchronized revision.

## Penpot UI

The three-way review panel now shows a resolution selector for every outstanding property:

- Keep Penpot
- Use DesignBridge

The **Apply property resolutions** action refuses to continue until every outstanding property has been resolved.
